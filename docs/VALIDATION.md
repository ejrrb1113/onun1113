# 첫 버전 검증 결과

검증일: 2026-10-28 / Node 24.19.0 / npm 11.9.0 / 시스템 Chromium

- `npm ci`: 잠금 파일 기반 재설치 성공
- `npm run build`: TypeScript 검사 및 Vite 배포 빌드 성공
- `npm test`: 9개 테스트 통과
- `npm run test:e2e`: PC 1440×1000 4개 / 모바일 에뮬레이션 390×844 4개, 총 8개 통과
- PC/모바일 모두: 키워드 검색, 복합 필터, 빈 결과·초기화, 상세·공유 링크, 즐겨찾기 재접속 유지, 17개 시도 표시·충남 드릴다운·전국 복귀, 위치 권한 허용 시 10km 거리 검색, 클러스터 확대·마커 선택, 다크모드, 가로 화면 넘침 없음 확인
- 카카오 키 없음 안내 확인. 실제 카카오 SDK 지도는 키 미제공으로 미검증
- 샘플은 51건, 17개 시도, 날짜 2026-10-28~11-15
- 실제 공공 API·Supabase·LLM·로그인·예약 알림·공개 배포는 이번 범위에 없으며 검증하지 않음
- 지도 배경 타일은 현재 클라우드 네트워크 정책상 표시되지 않음. 로컬 GeoJSON 경계·마커·행정구역은 외부 타일 없이 검증됨
- 모바일은 실제 기기가 아닌 Chromium 에뮬레이션
- 실제 GPS·카카오 길찾기 앱 전환·OS PWA 설치는 미검증

스크린샷: `screenshots/desktop.png`, `screenshots/mobile.png`.

프로덕션 PWA 추가 검증: `npm run preview -- --port 4173`에서 Chromium으로 서비스 워커 활성화 후 네트워크를 오프라인으로 전환하고 새로고침했습니다. 앱 셸 및 샘플 51개 카드가 복원됐습니다. 외부 지도 타일·카카오 SDK 오프라인 동작은 지원하지 않습니다.
